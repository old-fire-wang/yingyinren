版本：V1.0   日期：2026-05-22   所属产品：影印人工作台   文档状态：阶段2 纯文字版（原型占位）

1. 项目背景

影印人工作台目前已承载白衣渡江（需求文档流水线）、原型大天才、无中生有等能力，团队在日常使用 Cursor Agent 时大量沉淀了 Skill（SKILL.md 及配套目录）和 Markdown 说明文档，但这些资产分散在个人本机或聊天里，缺少统一的共享与取用入口。同学想复用某套 Skill 或参考某份 md，往往要私聊要文件，版本也不统一。 本次在顶栏新增「超级鬼市」Tab，做团队内轻量资产集市：能上传、列表浏览、下载，并在线预览 md 内容；所有人权限一致，降低 Skill/md 的流转成本，与影印人「需求—知识—Agent」定位一致。

2. 业务目标与衡量指标

2.1 业务目标

  • 在影印人 Web 内提供 Skill / Markdown 的统一上传、列表、下载与预览能力。
  • 支持 Skill 技能包（zip 解压目录）内多 md 文件浏览，满足「不只看 SKILL.md」的查阅需求。
  • 删除为物理抹掉，避免陈旧文件堆积占用磁盘。

2.2 衡量指标

指标说明目标（上线后 1 个月）
有效资产数列表中 md/skill 条目数（去重）≥ 20 条（团队主动上传）
下载次数详情页或列表触发下载可统计，周活跃下载 ≥ 10 次
上传成功率5MB 以内合法文件上传成功占比≥ 99%

3. 业务流程图

主流程（文字版，PNG 流程图见阶段3产出）：

  1. 用户登录影印人 Web，进入顶栏 Tab「超级鬼市」。
  2. 默认展示资产列表（文件名、类型、大小、上传人、上传时间）。
  3. 用户可将单个文件拖入上传区，或点击选择文件；服务端校验类型与 5MB 限制后落盘并刷新列表。
  4. 用户可点击某行「详情」：md 直接预览；skill 包展示文件树，点击树内 md 节点预览正文。
  5. 用户可「下载」：浏览器直接下载原 md 或 skill 包 zip。
  6. 任意用户可「删除」：二次确认后服务端物理删除数据库记录与磁盘目录/文件。

4. 功能清单

4.1 功能编号列表

  • F1 资产列表：展示已上传 md / skill，支持按名称搜索。
  • F2 拖拽上传：单文件上传区，支持拖拽与点击；一次传一个文件。
  • F3 下载：浏览器直接下载，无额外安装提示。
  • F4 详情预览：md 渲染；skill 包文件树 + 多 md 预览。
  • F5 物理删除：全员可删，抹掉 DB 与磁盘。
  • F6 鉴权：与影印人 JWT 一致，未登录不可访问。

4.2 功能详细说明

F1 资产列表 — 进入 Tab 即加载；表格列：展示名、类型（md / skill）、文件大小、上传人、上传时间；支持名称关键字过滤；每行提供下载、删除、查看详情操作。

F2 拖拽上传 — 页面顶部或列表上方固定上传区；接受 .md、SKILL.md、.zip（skill 包）；单文件 ≤ 5MB；上传中展示进度；失败需明确原因（超大、格式不符、包内无 SKILL.md 等）。

F3 下载 — md 下载原文件；skill 包下载 zip（与上传 zip 一致，或对解压目录重新打包）。

F4 详情预览 — 抽屉或独立详情区；md：全文 Markdown 渲染；skill：左侧目录树（包内全部文件），右侧预览选中路径的 md；非 md 文件仅展示文件名不可预览。

F5 物理删除 — 弹窗确认；成功后列表移除；服务端删除存储目录及 Prisma 记录，不可恢复。

F6 鉴权 — 沿用 /api/* JWT；与白衣渡江等同登录态。

6.1.2 详细设计

页面1：超级鬼市 · 列表与上传

【原型图见下文】

详细描述：

  • 页面用途：团队 Skill/md 资产的一站式浏览与上传入口。
  • 展示内容：拖拽上传区（说明「单文件 ≤ 5MB，支持 .md / .zip 技能包」）；资产表格；名称搜索框。
  • 操作说明：拖入或选择文件触发上传；行内「下载」「删除」「详情」；删除需二次确认文案「将永久删除，不可恢复」。
  • 跳转逻辑：点击「详情」打开详情抽屉，不离开 Tab。
  • 特殊说明：zip 上传后服务端解压，校验根目录或任意层级存在 SKILL.md，否则上传失败并提示。

页面2：超级鬼市 · 资产详情

【原型图见下文】

详细描述：

  • 页面用途：阅读 md / Skill 正文，浏览包内其他 md。
  • 展示内容：资产元信息（名称、类型、大小、上传人、时间）；类型为 md 时整页预览；类型为 skill 时左侧文件树、右侧 Markdown 预览区。
  • 操作说明：树节点点击切换预览 md；顶部或底部「下载」；关闭抽屉回到列表。
  • 跳转逻辑：关闭抽屉返回列表；无独立 URL 路由（V1）。
  • 特殊说明：预览仅支持 .md / .markdown 文本；其他扩展名显示「该文件不支持在线预览」。

6.2 服务端 API（影印人 API 扩展）

需支持接口（均需 JWT）：

  • GET /api/skill-market — 列表，可选 query 名称搜索。
  • POST /api/skill-market/upload — multipart 单文件，返回新资产 id。
  • GET /api/skill-market/:id — 元数据 + skill 文件树。
  • GET /api/skill-market/:id/content?path= — 指定相对路径 md 正文。
  • GET /api/skill-market/:id/download — 文件流下载。
  • DELETE /api/skill-market/:id — 物理删除。

存储：ECS 目录 storage/skill_market/{id}/；表 SkillMarketAsset 记录元数据。

9.1 需记录的日志

9.2 日志内容

写入现有 ServerExecutionLog 或专用操作表：操作人、操作时间、操作类型（upload/download/delete）、资产 id、结果（成功/失败及错误信息）。
