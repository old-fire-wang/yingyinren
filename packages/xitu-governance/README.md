# 稀土壁搜索治理平台｜本地体验版

这是一个本地运行的搜索无结果治理工具。对方拿到文件夹后，可以在自己的电脑上启动平台，配置自己的模型，然后上传无结果词文件进行 AI 分析，最后导出可导入同义词后台的 CSV。

## 1. 适合谁使用

- 运营、产品、业务同学想快速分析搜索无结果词
- 不想依赖研发部署
- 每个人可以配置自己的模型 Key
- 有公司数据平台权限的人，也可以用自己的 OA 和 AccessKey 跑 SQL

## 2. Windows 启动方式

1. 安装 Node.js LTS 版本  
   下载地址：https://nodejs.org/

2. 解压或打开这个项目文件夹

3. 双击下面任意一个：
   ```text
   START-Windows.bat
   启动-Windows.bat
   ```

4. 浏览器会自动打开：
   ```text
   http://localhost:5177/?v=share
   ```

5. 启动后不要关闭黑色命令行窗口。  
   关闭窗口后，本地服务也会停止。

## 3. Mac 启动方式

1. 安装 Node.js LTS 版本  
   下载地址：https://nodejs.org/

2. 双击下面任意一个：
   ```text
   START-Mac.command
   启动-Mac.command
   ```

3. 如果提示无法打开，右键文件选择“打开”。

## 4. 配置模型

进入页面后，点击右上角「配置模型」，填写：

- API Key：自己的模型密钥
- 模型：例如 `deepseek-v4-pro`、`gpt-4.1-mini`
- Base URL：模型服务地址

常见示例：

```text
OpenAI 官方：https://api.openai.com/v1
PackyCode 中转：https://www.packyapi.com/v1
```

保存后右上角会显示「模型已配置」。

## 5. 获取无结果词

有两种方式：

### 方式一：手动上传

点击「选择 TXT / CSV 文件」，上传无结果词文件。

支持字段：

```text
key_word,is_result,search_uv,search_pv
```

也支持只有一列搜索词的 TXT 文件。

### 方式二：自动跑数

如果你有公司 One-Service 权限：

1. 填写 OA 账号
2. 填写 AccessKey
3. 选择开始日期和结束日期
4. 点击「运行无结果 SQL」

没有数据平台权限的同学，直接用手动上传即可。

## 6. AI 分析

1. 确认已上传文件或已跑出 SQL 数据
2. 设置分析上限，默认 2000
3. 点击「开始 AI 分析」
4. 等待分析完成

分析过程中可以查看进度、日志，也可以取消任务。中断后可在「分析记录」里继续分析。

## 7. 审核和导出同义词

AI 分析完成后，进入「审核候选词」：

1. 勾选确认要导入同义词后台的词
2. 可点击「勾选全部可导入」
3. 点击「导出已勾选同义词」
4. 得到 CSV 文件

导出的 CSV 只包含：

```text
关键词,同义词
```

备注不写入导出文件，备注由运营在公司同义词后台自行填写。

## 8. 搜索概览

「搜索概览」会沉淀已 AI 分析过的真实无结果词，用于观察：

- 用户搜索画像
- 品类缺口
- 需要向搜索中台提的能力需求

点击「更新概览」可以基于历史分析任务重新生成概览。

## 9. 分享给同事前注意

推荐直接发送我给你打好的压缩包：

## 10. 常见问题

### 双击后提示找不到 node

说明电脑没有安装 Node.js。安装 Node.js LTS 后重新双击启动。

### 页面打不开

确认启动窗口没有关闭，并访问：

```text
http://localhost:5177/?v=share
```

### AI 分析失败

优先检查：

- API Key 是否正确
- Base URL 是否正确
- 模型名是否正确
- 模型服务是否超时或限流

### 运行 SQL 失败

优先检查：

- OA 是否正确
- AccessKey 是否正确
- 是否有 One-Service 权限
- 日期范围是否正确
